These files are part of my Master project and contain functions that I use to calculate X-ray luminosity from binary systems. 

This first part of my work is based on reproducing the Figure 1 from Misra et al. (A&A 672, A99 (2023))

Input data must be from POSYDON Population class with some specific data. 
It takes into account Roche-Lobe overflow and winds from the companion star,
often called the secondary or donor star, as well as the type of the compact accretor. 

Then, once the population went through my functions, I have a population of binary systems containing a black hole or neutron star with a Main sequence star or post main sequence star (H-rich or He-rich star). This companion is loosing mass either by filling its own Roche lobe (for lighter stars), leading to Roche lobe overflow or by wind (for massive stars). These physical processes allow to create an accretion disk around the compact object which allows to accrete this material and then produce X-rays.

These systems are called X-ray binary systems (XRBs).
